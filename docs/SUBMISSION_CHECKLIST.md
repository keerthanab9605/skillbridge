# LaunchED submission checklist
Official guideline deadline: **10 Oct 2026** (no extensions). Contact support@launched.org.in if you are past it.

- [ ] Project deployed; live URL works (Vercel + Render + Atlas), seed data loaded
- [ ] Code pushed to GitHub (public or access granted), CI is green
- [ ] Figma file shared ("Anyone with the link can view")
- [ ] Technical documentation + Capstone Report finalised (fill in the [brackets], add screenshots, export PDF)
- [ ] One Google Drive folder with: code zip, docs, report, Figma link, URLs. Sharing = **Anyone with the link can view**
- [ ] Demo video: 5–10 min, **MP4**, English intro (name, college, course & branch, year, domain, LaunchED experience, title + one-line overview), walkthrough covering problem, tools, architecture, functionality, live demo, challenges, results
- [ ] Video uploaded to Google Drive separately, view access on
- [ ] LinkedIn post with the video: what you built, tech used, outcomes & learnings, personal experience. **Tag LaunchED and your HOD**
- [ ] Google review posted (text only, no images) at https://g.page/r/CeJX6LExaYbwEAE/review, then screenshot it
- [ ] Final Google Form: Drive folder link, Drive video link, LinkedIn post link, review screenshot
