# Figma design file: what to include
Create one Figma file named **SkillBridge** with desktop (1440) and mobile (390) frames, light and dark variants. Share link as "Anyone with the link can view".

**Styles first:** colors (ink-900 #0F1B2D, ink-50 #F4F7FA, span-600 #0B7A83, signal-500 #F2A33A), text styles (Bricolage Grotesque 36/24/18 bold, Source Sans 3 16/14), 8px spacing grid.

**Screens (match the built app):**
1. Jobs home: hero with search + filters, 3-column job cards, pagination
2. Job detail with apply panel
3. Login and Register (student / recruiter toggle)
4. Student dashboard: stat cards, pipeline chart, tracker table, saved jobs
5. Profile with resume upload
6. Recruiter hub: stats, post-job form, applicants table with status select
7. Admin dashboard: stats and users table
8. Mobile versions of 1, 2, 4 and the collapsed menu

**Components:** button (primary/ghost/danger), input, job card, status badge, navbar. Link the prototype flow Login → Dashboard → Job → Apply.
